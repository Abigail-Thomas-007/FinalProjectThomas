# FinalProjectThomas
Project Option
I am chosing to build a Responsive Website for my project. 
Working Title
The title I chose for my project is Mission: Meteoroid. 
Space Theme Interpretation
My project responds to the theme of Space as it is an interactive mission briefing revolving around the idea of prepping astronauts for space travel and alien worlds. 
Project Description
My project is an interactive site that functions as a mission briefing. Users or players will find themselves on a sleek site with options to sort through the information needed for their mission. They will expand and collapse information paragraphs, open connected pages with more detailed descriptions of different places, things, or creatures they are expected to encounter. To navigate this site, there will be clear tabs, links, and buttons. This experience will be interesting as it tells a story as the site tells a story as users navigate through it. It will feel like the user or player has been recruited into an exclusive mission with high stakes. HTML will serve as a base code for my project. It’s where I will write the majority of the text and code needed to make the site usable. I will use CSS to keep a consistent style throughout the site. Finally, I will write JavaScript so the site is more interactive and functions correctly as users and players click buttons and links. 
Intended User or Player
The intended audience for your project is young or teenage users with interests in adventure, space, and sci-fi. They should not need to have a high experience level to successfully navigate my project. Because I am aiming to design this site for a younger age group, I will need to make the buttons and clickable spaces clearly defined. They will likely have expectations of entertaining graphics and easily legible paragraphs as well.  
Main User or Player Goal
The user or player should be able to learn about a fictional planet and it’s creatures and navigate an interactive storyline.
